##  Descripción del Proyecto

El proyecto consiste en el diseño e implementación del sistema de información para una **empresa terminal automotriz** dedicada al ensamblaje de vehículos. El sistema abarca la gestión de:
* Líneas de montaje y estaciones de trabajo.
* Proveedores e insumos necesarios bajo la modalidad *Just in Time*.
* Control de producción y seguimiento de vehículos mediante números de chasis/patentes.
* Red de concesionarios y gestión de pedidos de vehículos.
